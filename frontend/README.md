# WiaNews — 기술 뉴스레터 프론트엔드

React 19 + Vite 기반 데스크톱 UI입니다. 도메인 추천은 Python 백엔드와 연결되어 있습니다. 전체 실행 방법은 [프로젝트 README](../README.md)를 참고하세요. `/home/wia/projects/weekly_report/frontend`의 블루 계열 색상, 좌측 내비게이션, 패널 구성을 참고했습니다. 권장 화면 너비는 1280px 이상이며 최소 너비는 1120px입니다.

## 실행

```sh
cd /home/wia/projects/wianews/frontend
npm install
npm run dev -- --port 6111 --strictPort
```

개발 주소: http://localhost:6111 · 백엔드는 127.0.0.1:6112에서 실행합니다.

```sh
npm run build
npm test
```

## 사용자 흐름

1. 관심 주제 하나(최대 120자)를 입력하고, 같은 단계의 도메인 목록 박스에서 수집 출처를 관리합니다. AI 추천 팝업은 기본 전체 선택이며, 선택한 후보만 목록에 추가됩니다. 직접 추가·삭제는 목록 박스에서 수행하며 총 20개까지 등록합니다.
2. 다음 단계에서 수집 기간을 설정합니다. 이전 단계로 돌아가도 주제·도메인·기간이 유지됩니다.
3. 수집·검증·중복 통합·중요도 평가를 시뮬레이션합니다. 수집 뉴스와 선정 이슈, 점수 내역을 확인합니다.
4. 상위 5개 이슈로 HTML 뉴스레터를 생성합니다. 제목 수정, HTML 다운로드, 보관함 저장을 지원합니다.

## 구현 범위와 연동 지점

- **도메인 추천은 실제 AI 호출입니다.** `src/api.js`가 `/api/domains/recommend/stream`를 호출하여 완성된 출처부터 하나씩 표시합니다. 팝업은 로딩·재시도·빈 결과를 처리하고 사이트 설명, 추천 이유, 주제 관련성을 표시합니다. 사이트 접속 검증과 뉴스 크롤링은 수행하지 않습니다.
- 뉴스는 `collectDemo`가 만드는 명시적인 가상 데이터입니다. 선택 도메인과 기간을 반영하며 발행일은 선택한 종료일로 설정합니다. 링크는 홈페이지 링크입니다. 실제 기사나 검증된 발행일로 사용하면 안 됩니다.
- `rankNews`는 이슈 ID로 중복을 묶고 중요성 35%, 업무 연관성 30%, 파급력 25%, 최신성 10%를 가중 합산합니다. 예시 점수는 고정되어 있으며 70점 이상 상위 5개를 선택합니다.
- 뉴스 수집 연동 시 `collectDemo`와 고정 점수 생성을 백엔드 호출로 교체하고 기사 원문 URL·발행일·검증 결과·이슈 그룹·근거가 포함된 응답을 연결하면 됩니다.
- `newsletterHTML`은 핵심 요약·선정 이슈·업무 시사점·출처를 인라인 스타일 HTML로 생성합니다. 사용자 입력은 HTML 이스케이프 처리합니다.
- 보관함은 해당 브라우저의 `localStorage`에 최근 30개를 저장합니다. 입력 중인 설정은 새로고침 시 초기화됩니다.
- 정기 실행, 서버 저장, 로그인, 메일 발송 기능은 포함하지 않습니다.
- Pretendard Regular/Medium/SemiBold/Bold를 `public/fonts`에서 로컬 로드합니다. 외부 폰트 접속 없이 한글을 표시하며, 폰트 라이선스는 `public/fonts/LICENSE.txt`에 포함했습니다.

## 파일 구조

- `src/main.jsx`: 주제·도메인 → 수집 기간 → 분석 → 뉴스레터 흐름
- `src/DomainSetup.jsx`: 첫 단계 도메인 관리 박스와 AI 추천 선택 팝업
- `src/styles.css`: 데스크톱 스타일
- `src/api.js`: 백엔드 도메인 추천 API 호출
- `src/lib.js`: 도메인 형식 검증·예시 뉴스·선정·HTML 생성
- `src/lib.test.js`: 도메인 검증, 선정, HTML 이스케이프 테스트

## 스케줄링 관리 (프론트엔드)

사이드바의 ‘스케줄링 관리’에서 보관함에 저장한 뉴스레터를 선택해 스케줄을 만듭니다.
매일·매주(복수 요일)·매월의 발행 주기, 시작일을 설정합니다. 발행 시간은 한국 시간 오전 8시로 고정합니다. 수집 기간은 이전 실제 발행일(첫 발행은 설정한 시작일)부터 이번 발행일까지 양쪽 날짜를 포함하는 고정 규칙입니다. 최근 N일 옵션은 사용하지 않습니다. 실제 발행 이력에 따른 수집은 추후 구독 백엔드에서 구현합니다.
월별 실행일이 해당 월에 없으면 월말을 예상일로 표시합니다.
수정, 사용 설정 전환, 검색·상태 필터, 삭제·되돌리기를 지원합니다.
`wianews-schedules-v1` localStorage에만 저장하며 실제 예약 실행, 메일 발송, 백엔드 API는 구현하지 않습니다.
예상 실행일은 프론트엔드 계산 결과입니다. 원본 뉴스레터가 보관함에 없으면 원본 확인 필요 상태를 표시합니다.
관련 파일: `src/Scheduling.jsx`, `src/schedules.js`, `src/scheduling.css`.
